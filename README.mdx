

#### 技術的提案（追加機能・表現）
- 光源位置の変更  
  - GUIで光源座標（vec3）を調整できるスライダーを追加
  - 複数光源に対応した設計（directional, point, spot light）

- 座標表示  
  - SDFにてx, y, z軸の線分を描画し、原点付近に固定表示
  - ラベル表示（GLSL内の2D投影計算 or テクスチャ合成）

- マテリアル高度化  
  - 法線マップの導入（疑似テクスチャ or procedural）
  - Cook-Torranceモデル（物理ベースレンダリング）
  - 屈折、薄膜干渉（GLSLベースでシミュレーション）
  - テクスチャベースの roughness, metalness の導入

- 図形の追加  
  - 点群 = SDF内に「球の集合」（点ごとにSDFを最小値合成）
  - 線分 = capsule SDF を連結（スプラインも可能）
  - GUIで点/線の追加・削除・移動

- パラメータ保存・ロード  
  - `localStorage`ベースの保存・読込
  - JSON形式でのexport/import機能（ファイル保存にも対応）

#### 実現が難しい・注意が必要な点
- 複数光源・反射をリアルに模擬するにはレイマーチの多重化が必要（パフォーマンス低下に注意）
- 複雑な材質（多層反射など）はWebGLの制限下では計算量が制約
- 点群・線分を大量に扱う場合はSDFでのリアルタイム更新が難しい（データ構造の最適化が必要）

#### 追加で検討すべき案
- GUIを使ってプリセット選択（例：標準ライティング・形状・カメラ構成）
- ノイズ関数（Perlin, Simplex, FBM）を使ったマテリアル変調
- 距離ベースのエフェクト（例：fog, depth glow, outline）
- GLSL側のライブエディット機能（CodeMirrorと連携）

#### マテリアル表現の高度化方向（箇条書き）
- Lambert / Blinn-Phong（基本）
- Cook-Torrance（物理ベース）
- Anisotropic BRDF（布地、髪など）
- Subsurface Scattering（皮膚、ろうそく）
- Thin-film interference（シャボン膜、油膜）
- Emissiveマテリアル（光るオブジェクト）
- 環境マッピング（反射・屈折環境）

#### 保存方法の追加案
- PNG以外にもEXRやTGA対応（ブラウザ制限を考慮）
- 透過背景PNG（アルファ有効化）
- ZIP化して複数フレーム保存（将来的な拡張用）
